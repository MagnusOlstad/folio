Local LLM filing

One field. The model files it. You confirm.

Press Cmd Enter and the selected local model reads the whole note and proposes a path, title, type and tags. Every capture stays one note; it is never split apart.

  • Reuses your existing folders and tags instead of inventing new ones
  • Todos append to one todo list, daily notes to a note per day
  • Nothing is saved until you accept the proposal

New in 0.8

Read images. Translate notes.

Read text in images

Choose Extract text on any image in a note. LightOnOCR 3 1B runs on your Mac through MLX and returns the text for you to copy or insert.

  • Preview first, then Copy or Insert into the note
  • Results are cached per image
  • Words inside screenshots, scans and whiteboard photos are searchable

LightOnOCR 3 1B, about 2.02 GB, downloaded on request.

Translate your notes

Turn on auto-translate for a note and read it in Norwegian or English with one toggle. The translated view is read-only and stays current in the background.

  • EN/NO toggle in the note header, instant once translated
  • Code, links and formatting are preserved
  • Translate and export to English, Norwegian Bokmål, German, Spanish, French, Finnish, Swedish or Danish

Uses your selected local generation model. Nothing leaves the Mac.

Search and Ask

Find it, or ask it.

Search combines metadata, lifecycle, relationships, keywords and EmbeddingGemma embeddings, including the text inside your images. It never loads the larger answer model.

Ask uses the model you selected to write a grounded answer with links to the notes it cites.

And everything around it.

  • Transcripts

    Import AAC, AIFF, FLAC, M4A, MP3 or WAV. Whisper large-v3-turbo transcribes on your Mac into an editable note.

  • Version history

    Every note keeps earlier versions you can restore. Refiling keeps the history.

  • Links and backlinks

    Indexed from Markdown links and sources. Related notes become links only when you confirm.

  • Small local models

    Qwen 3.5 4B, Llama 3.2 3B Instruct or Gemma 4 E4B through MLX, plus EmbeddingGemma for search.

  • Markdown and PDF export

    Export filed notes and local drafts.

  • Lifecycle states

    Draft, stable or deprecated, with a stale-after date.

  • Multiple bundles

    Separate note collections, switchable in Settings. Back up from Settings or copy the folder.

  • Familiar shortcuts

    Cmd+B, Cmd+I, Cmd+K, Cmd+Shift+F and more. Click a tag to filter exactly.

Agent-first storage

Your notes are an open knowledge base.

FolioNotes writes Open Knowledge Format v0.2: Markdown with frontmatter for provenance, lifecycle state and generation metadata. Every capture is also kept as an immutable raw note.

It is just a folder of files, so any AI agent, script or editor can read it without an API.

Questions.

Which languages can it translate?

The live translated view works between Norwegian and English. Translate and export supports English, Norwegian Bokmål, German, Spanish, French, Finnish, Swedish and Danish.

Does it work on Intel, Windows or Linux?

No. FolioNotes runs its models with MLX, which requires a Mac with Apple Silicon (M1 or later).

Where are my notes stored?

In ~/Documents/Folio, as Markdown files with OKF frontmatter, along with the search index. Open the folder in Finder or any editor.

Can I take my notes with me?

Yes. Your notes are plain Markdown in an open format, so you can copy the folder, open it in another tool, or point an AI agent at it.

Is it free, and how do updates work?

It is free and open source under the MIT License. The app checks GitHub Releases and installs signed updates, or you can download the latest version from the Releases page.
