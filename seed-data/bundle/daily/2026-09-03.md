## How to add a daily entry

Create a new note whose first non-empty line begins with `daily:`. For example:

```text
daily: Finished the first project milestone and noted the next decision.
```

Folio appends the entry to `/daily/YYYY-MM-DD.md` using your local date and time. Multiple daily captures on the same day are collected in the same file.
