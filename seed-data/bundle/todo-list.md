# Todo List

- [ ] Add your first task: create a new note beginning with `todo:`, such as `todo: Review my project plan`, then file it.

Every capture whose first non-empty line begins with `todo:`, `task:`, or `to-do:` is appended here as a checkbox. Longer captures can continue on following lines.

Select a checkbox to complete or reopen a task. You can also select the note body to edit the list directly.
