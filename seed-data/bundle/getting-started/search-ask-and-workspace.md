# Search, Ask, and Work with Notes

## Find information

- **Explorer** browses the Markdown bundle by directory.
- **Search** combines words, metadata, relationships, and semantic similarity. Exact tags can be selected as filters.
- **Ask** retrieves relevant notes and asks the selected local model to synthesize an answer. Source links in the answer open the supporting notes.

Search and relationship ties prefer the most recently edited note.

## Work with several notes

- Select **Split** to open an empty second editor pane.
- Drag tabs between panes.
- Drag the sidebar divider or the divider between split panes to resize them.
- Double-click a divider to reset it.
- The footer shows path, tags, state, last edited time, and frontmatter links.

## Maintain the bundle

- Drag a file onto an Explorer directory to move it.
- Edit the footer path for precise filing.
- Select **Reindex** after changing Markdown files outside Folio.
- Delete obsolete drafts with their `x` control.
- Delete obsolete filed notes from their footer. Raw captures remain available for recovery.

Folio automatically updates links when a note is moved and reuses embeddings when their source text has not changed.
