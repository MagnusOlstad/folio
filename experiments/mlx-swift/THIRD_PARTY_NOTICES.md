## GLiNER2.5 Multi model checkpoint

Folio's native GLiNER2.5 Multi implementation loads the checkpoint
`fastino/gliner2.5-multi-v1` at Hugging Face revision
`7b005274e82da37dcf1f5fd9d6a2ef413c6a004c`. The model card identifies the
checkpoint as Apache License 2.0. The model weights are obtained separately
through the explicit native install operation and are not bundled in Folio.
